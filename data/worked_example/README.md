# Worked-example records (Chapter 3 / Appendix A.5)

Serialized output of the one-off live System 1 spot-check of the two Chapter 3
worked examples ("I call my brother for help, then I burn the whole city down."
and its companion), recorded on July 17, 2026 against the chapter's
original-nightmare context. This was a limited verification call, not a
benchmark run.

- `worked-example-live-verification.json` — complete serialized responses of
  both examples, written by `thesis/scripts/verify_chapter3_revised_examples.py`.
- `worked-example-structured-output.json` — the `SafetyResult` of the mixed
  example, extracted from the file above by
  `thesis/scripts/generate_chapter3_revised_artifacts.py`.
- `worked-example-constraint.txt` — the constraint string of the mixed example,
  reproduced verbatim in the thesis appendix ("Worked Constraint Message").
